# The Hidden Benefits of AI-Assisted Documentation

Now,
let me share something that really surprised me about using AI for documentation.
I found that the process of creating and refining documentation
with AI often led me to improve my actual code.

How? Well,
in explaining concepts to the AI (and by extension, to my future users),
I sometimes realized that certain parts of my code weren’t
as intuitive or well-structured as I thought.
This led me to refactor and improve the code itself.

Moreover,
comprehensive documentation generated
by AI sometimes helped me identify edge cases
or potential features I hadn’t considered.
It was like having a thorough,
impartial reviewer for both my code and my thought process.
