# Goal Definition

## Define the "Why" and the "What."

- **Define Core Problem:** What specific problem are you solving?
- **Define MVP (Minimum Viable Product):** What is the absolute minimum feature set required for this to be functional?
- **Research:** Check existing solutions. What makes your approach different or better?

### Example

- **Core Problem:** Create a fast, efficient, terminal-based to-do list manager for developers.
- **MVP Features:**
  - Initialize/Load task file (`file.json`).
  - Add tasks.
  - Delete tasks.
  - Mark task status (done, in-progress, not-done).
  - List tasks with filtering by status.
- **Differentiation:** Optimized for keyboard-only interaction, lightweight, and local storage (no external API dependencies).
